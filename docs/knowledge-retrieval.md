# Knowledge Retrieval

Keep durable instructions small and retrieval focused. `always.md` contains rules that should apply every session; contextual notes hold focused procedures. `index.json` maps topics to concise descriptions and relative paths.

## Read policy

1. Read the knowledge README and `always.md` at session start.
2. Search the index for the current task and open only matching notes.
3. Verify time-sensitive facts against current project evidence.
4. Prefer a small excerpt or summary over loading an entire archive.

## Write policy

Write rarely. Add a contextual note only when it captures reusable guidance that is absent from project documentation. Keep notes generic, evidence-backed, dated when freshness matters, and free of credentials or personal data. Update the index with each addition and remove stale instructions when they no longer apply.

The example under `templates/knowledge/` shows the minimal structure.
