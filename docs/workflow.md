# Workflow Overview

Use the smallest process that makes the work verifiable and safe.

1. Read repository instructions and current evidence.
2. Classify the work by effect and uncertainty.
3. Write an intent or spec appropriate to the tier.
4. Make a scoped change and keep noisy output compact.
5. Run affected checks and inspect the final diff.
6. Finish the branch when authorized; record a concise handoff for non-trivial work.
7. Route eligible deployment intent through the shared coordinator.

See [Work Tiers](work-tiers.md), [Review Policy](review-policy.md), and [Branch Finishing](branch-finishing.md).
