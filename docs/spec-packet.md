# Spec Packet

Use a saved packet when it materially improves execution, recovery, or handoff. Extend an existing plan when it already captures the needed decisions; omit irrelevant sections.

## Outcome and boundaries

Describe intended behavior, scope, exclusions, and compatibility constraints.

## Acceptance and validation

List observable success criteria and affected checks or live evidence.

## Approach and risks

Record decisions, dependencies, failure modes, and unresolved questions.

## Rollout and rollback

For persistent or live changes, specify rollout order, stop conditions, and a rollback path that preserves existing data.

## Handoff

Name the current owner, evidence locations, and one concrete next action.
